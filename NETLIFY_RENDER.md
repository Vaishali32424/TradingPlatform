## Step 2 — MongoDB Atlas

1. Log in to [MongoDB Atlas](https://cloud.mongodb.com).
2. Create a cluster (free tier is fine).
3. **Database Access** → create a user + password.
4. **Network Access** → **Add IP Address** → **Allow Access from Anywhere** (`0.0.0.0/0`) so Render can connect.
5. **Connect** → **Drivers** → copy the connection string, e.g.  
   `mongodb+srv://USER:PASSWORD@cluster.xxxxx.mongodb.net/trading_platform`
6. Replace `<password>` with your password. If the password contains `@`, encode it as `%40`.

## Step 3 — Deploy backend on Render

1. Go to [dashboard.render.com](https://dashboard.render.com) → **New +** → **Blueprint**.
2. Connect GitHub → select **Vaishali32424/TradingPlatform**.
3. Render reads `render.yaml` and creates the **tradingplatform-api** service.
4. When prompted, set these **environment variables**:

| Key | Value |
|-----|--------|
| `MONGODB_URI` | Your Atlas connection string |
| `CLIENT_URL` | Your Netlify URL (set after Step 4), e.g. `https://your-app.netlify.app` — you can add `,http://localhost:5173` for local dev |
| `SUPERADMIN_PASSWORD` | Strong password for first login |
| `JWT_SECRET` | Auto-generated by Render (or set your own long random string) |

5. Click **Apply** / deploy. Wait until status is **Live**.

**Render settings (required — fix “No open ports detected”):**

| Setting | Value |
|---------|--------|
| **Root Directory** | `backend` |
| **Build Command** | `npm install && npm run build` |
| **Start Command** | `npm start` (not `npm run dev`) |
| **Instance type** | Web Service |

6. Copy your API URL, e.g. `https://tradingplatform-api.onrender.com`
7. Test: open `https://YOUR-API.onrender.com/api/health` → should show `{"status":"ok","db":"connected"}`.

**Seed super admin (if login fails):** Render → your service → **Shell** → run:

```bash
npm run seed:prod
```

Login: `superadmin` / password from `SUPERADMIN_PASSWORD`.

---

## Step 4 — Deploy frontend on Netlify

1. Go to [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project**.
2. Connect **GitHub** → choose **TradingPlatform**.
3. Netlify should detect `netlify.toml` automatically:
   - **Base directory:** `frontend` (from netlify.toml)
   - **Build command:** `npm ci && npm run build`
   - **Publish directory:** `frontend/dist`
4. Add **environment variable** (required):

| Key | Value |
|-----|--------|
| `VITE_API_URL` | `https://YOUR-API.onrender.com/api` |

Replace `YOUR-API` with your real Render hostname (no trailing slash before `/api`).

5. Click **Deploy site**. Copy the Netlify URL, e.g. `https://random-name.netlify.app`.

---

## Step 5 — Link frontend and backend (CORS)

1. **Render** → your API service → **Environment** → edit `CLIENT_URL`:

```
https://your-app.netlify.app,http://localhost:5173
```

Use your real Netlify URL (no trailing slash).

2. **Save** → Render will redeploy.

3. **Netlify** → **Site configuration** → **Environment variables** — confirm `VITE_API_URL` points to Render `/api`.

4. **Netlify** → **Deploys** → **Trigger deploy** → **Clear cache and deploy site** (rebuilds with correct API URL).

---

## Step 6 — Verify

1. Open your Netlify URL.
2. Log in as `superadmin` with your `SUPERADMIN_PASSWORD`.
3. If you see CORS errors in the browser console, double-check `CLIENT_URL` on Render matches the Netlify URL exactly.

## Environment cheat sheet

### Render (backend)

```
MONGODB_URI=mongodb+srv://...
JWT_SECRET=long-random-string
CLIENT_URL=https://your-app.netlify.app,http://localhost:5173
SUPERADMIN_PASSWORD=YourSecurePassword123!
RUN_SEED=true
```

### Netlify (frontend)

```
VITE_API_URL=https://tradingplatform-api.onrender.com/api
```

### Local dev

`backend/.env` — same as before with `CLIENT_URL=http://localhost:5173`  
`frontend/.env` — `VITE_API_URL=http://localhost:5000/api`

## Notes

- Render **free** tier sleeps after inactivity; first request may take ~30s.
- Profile **uploads** on Render use ephemeral disk; avatars may reset on redeploy. For production, use S3/Cloudinary later.
- Never commit `.env` files — only `.env.example`.
